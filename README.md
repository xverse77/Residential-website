# Aurea House

A one-page marketing site for Aurea House, a collection of twelve private garden residences in Claremont, Cape Town. It has an editorial, earthy design with a full-screen hero, a story section, featured residences, amenities, location details and a private-viewing enquiry form. Scroll reveals, parallax images, a scroll progress bar and a mobile menu are written in plain JavaScript and CSS, and the site respects reduced-motion settings.

## Live site

https://xverse77.github.io/Residential-website/

## Run locally

```bash
npm install
npm run dev
```

Then open the address Vite prints (usually http://localhost:5173/).

## Build

```bash
npm run build
```

The production files are created in the `dist` folder. Pushing to `main` deploys the site to GitHub Pages automatically.

## Built with

- [Vite](https://vitejs.dev/)
- Vanilla JavaScript and CSS
